三进制称量（次品球）问题的严格建模、上界与可构造算法

摘要

研究经典“次品球”问题：给定 nnn 个外观相同的球，恰有一个次品（可能偏重或偏轻），使用同一台等臂天平进行 MMM 次称量，是否可以确定次品的位置并判断轻重。本文在**物理等臂天平（每次称量两边数量必须相等）**的约束下，给出：

  • 信息论上界与其可达性；
  • 与“理想三值模型”的等价性说明；
  • 一个可实现的编码构造算法（含验证代码）；
  • 在非满容量情形下的构造与分解策略。

1. 模型与符号

1.1 物理等臂天平模型

  • 有 nnn 个球，恰有一个为次品；
  • 次品可能偏重或偏轻；
  • 进行 MMM 次称量；
  • 每次称量：左右两盘球数相等；
  • 观测结果为三值：{−1,0,+1}\{-1,0,+1\}{−1,0,+1}（右重/平衡/左重）。

1.2 编码矩阵表述

用矩阵

A∈{−1,0,1}M×nA \in \{-1,0,1\}^{M\times n}A∈{−1,0,1}M×n

描述称量方案：

  • 第 jjj 列对应第 jjj 个球；
  • 第 iii 行对应第 iii 次称量；
  • Aij=+1/−1/0A_{ij}=+1/-1/0Aij​=+1/−1/0：分别表示该球在第 iii 次称量中放在左/右/不参与。

若第 jjj 个球是：

  • 重球：观测向量 r=A⋅jr = A_{\cdot j}r=A⋅j​；
  • 轻球：r=−A⋅jr = -A_{\cdot j}r=−A⋅j​。

1.3 合法性条件

一个可用方案必须满足：

  • (C1)\text{(C1)}(C1) 判别性：不存在零列，且 A⋅j≠±A⋅k(j≠k)A_{\cdot j} \neq \pm A_{\cdot k}\quad (j\neq k)A⋅j​=±A⋅k​(j=k)
  • (C2)\text{(C2)}(C2) 等数量约束（行平衡）： ∀i,∑j=1nAij=0\forall i,\quad \sum_{j=1}^n A_{ij} = 0∀i,j=1∑n​Aij​=0

2. 信息论上界

定理 1（上界）

n≤3M−32\boxed{n \le \frac{3^M - 3}{2}}n≤23M−3​​

证明要点

  • MMM 次称量最多产生 3M3^M3M 种结果；
  • 实际可能结果不含全零（因为一定有次品）；
  • 每个球对应两种状态（重/轻），且结果向量成对出现：±r\pm r±r；
  • 因此可区分的球数满足： 2n≤3M−1  ⇒  n≤3M−122n \le 3^M - 1 \;\Rightarrow\; n \le \frac{3^M-1}{2}2n≤3M−1⇒n≤23M−1​
  • 排除零向量对应的不可用情况，得到： n≤3M−32n \le \frac{3^M-3}{2}n≤23M−3​

3. 上界的可达性（关键结论）

定理 2（可达性）

在等臂天平约束下，存在满足 (C1)(C2)\text{(C1)}\text{(C2)}(C1)(C2) 的编码矩阵 AAA，使得：

n=3M−32n = \frac{3^M - 3}{2}n=23M−3​

解释

这意味着：

物理约束（左右等量）并不会降低最大可区分球数。

该结论可通过平衡三进制码（balanced ternary code）的构造或差分（discrepancy）理论保证。

4. 与“理想三值模型”的关系

  • 理想模型允许左右数量不等；
  • 物理模型增加了约束 (C2)\text{(C2)}(C2)；
  • 但通过全局平衡构造，两者在最大容量上等价。

5. 构造方法（算法化）

5.1 构造思路

考虑集合：

V={v∈{−1,0,1}M∣v≠0}\mathcal{V} = \{v \in \{-1,0,1\}^M \mid v \neq 0\}V={v∈{−1,0,1}M∣v=0}

将其按对分组：

{v,−v}\{v,-v\}{v,−v}

从每一对中选择一个向量，使：

  • 不选取互为相反数的列；
  • 所有列向量逐行求和为 0。

5.2 算法（贪心平衡）

  1. 枚举所有 (v,−v)(v,-v)(v,−v) 对；

  2. 随机打乱顺序；

  3. 逐对选择：

    • 在 vvv 与 −v-v−v 中选一个，使当前“行不平衡度”最小；

  4. 若最终达到行和为 0，则构造成功。

7. 非满容量情形（n<nmax⁡n < n_{\max}n<nmax​）

定理 3

只要

n≤3M−32n \le \frac{3^M - 3}{2}n≤23M−3​

则存在合法方案。

构造策略

方法一：子集选择 + 再平衡

  • 从最大解中选取 nnn 列；
  • 调整列符号（交换左右）恢复行平衡。

方法二：递归三分（经典）

每次称量：

  • 将球分为三组：左、右、不参与；
  • 且左右数量相等；
  • 根据结果递归缩小范围。

8. 常见误区

❌ 误区 1：必须“支撑向量成对”

这是在求解“子集和为零”的问题， 而不是设计整体编码矩阵。

❌ 误区 2：删列一定破坏平衡

错误。 删除后通过**符号翻转（列取反）**可以恢复平衡。

9. 本质数学结构

该问题等价于：

  • 三值编码（ternary codes）
  • 差分理论（discrepancy theory）
  • 三叉判定树（ternary decision trees）

10. 结论

  • 最大球数： nmax⁡=3M−32\boxed{n_{\max} = \frac{3^M - 3}{2}}nmax​=23M−3​​
  • 在物理等臂天平下仍然可达；
  • 可通过平衡三进制编码构造；
  • 非满容量情形可通过子集调整或递归策略解决。
