前言：在频域“一刀切”的代价

在《痛苦系列 02》中，我们讨论了如何借助傅里叶变换将时域波形映射到频域。处理混有高频肌电毛刺的心电（ECG）信号时，一个直接的想法是在频域用矩形掩模做置零：把截止频率以外的谱线全部清零，再做一次逆变换回到时域。

但对包含尖锐 QRS 波群的信号做这种频域硬截断，逆变换回时域后往往会在跳变边缘出现明显的起伏振荡（振铃效应，Ringing），在有限长数据帧下还会叠加循环卷积带来的边界失真。

其根本原因在于频域与时域之间存在变换对偶约束：频域中剧烈的阶跃突变，对应着时域中缓慢衰减、长距离延伸的振荡冲激响应。与此同时，实时监测设备也无法等待整段信号采集完毕后再做离线全局变换，系统需要逐样本在线流式滤波。

本篇聚焦于数字信号处理中最基础的实时滤波器形态——有限冲激响应滤波器（FIR, Finite Impulse Response）。全文同时梳理数学推导与工程实现：FIR 在代码里如何组织，主瓣与旁瓣如何作用于输出波形，以及 firwin 与 remez 在参数设计、延迟对齐与结构约束上的工程要点。

一、 保真诉求：幅频、线性相位与波形保真的边界

在工程实践中，平滑一段带有高频毛刺的传感器数据，最直观的做法是滑动窗口加权平均（Moving Average）。当前时刻的输出，仅由当前及过去有限个输入样本加权累加得到：

y[n]=∑k=0L−1h[k]x[n−k]y[n] = \sum_{k=0}^{L-1} h[k] x[n-k]y[n]=∑k=0L−1​h[k]x[n−k]

对应到内存与执行层，FIR 滤波器就是两个长度均为 L 的数组：一个存放预先算好的静态浮点权重 h[0..L-1]，另一个是保存最近 L 个历史采样点的环形缓冲区（Ring Buffer）。每当新样本到达，将其写入缓冲区覆盖最旧样本，再对两个数组做一次点积（乘加累加，MAC），即得到当前时刻的输出。

在本篇中，我们统一采用以下符号约定：

  • L 表示抽头长度（抽头数，Number of Taps）：即权重数组 h 包含的系数总个数（n=0,1,…,L−1n = 0, 1, \dots, L-1n=0,1,…,L−1），直接决定了每次采样的乘加运算量和历史缓存大小；
  • N = L - 1 表示滤波器阶数（Filter Order）：对应系统传递函数 H(z)=∑k=0Nh[k]z−kH(z) = \sum_{k=0}^{N} h[k] z^{-k}H(z)=∑k=0N​h[k]z−k 中延迟算子 z−1z^{-1}z−1 的最高幂次。由于分母恒为 111（所有极点均收敛于原点 z=0z = 0z=0），有限长 FIR 系统不存在反馈回路，天然满足有界输入有界输出（BIBO）稳定。

作者按：在生物医学信号处理（如 ECG 心电、EEG 脑电）或高保真音频分频中，工程师即便面对较高的乘加计算开销，也常常优先选用 FIR 滤波器。这并不是因为 FIR 的幅频滚降比 IIR 更好，而是因为 FIR 能够极其方便地利用对称系数构造严格的线性相位（Linear Phase）。

线性相位为什么关乎波形保真？它等同于“绝对保真”吗？

现实中的复杂生理或瞬态信号（如心电图的 QRS 波群），本质上是由许多不同频率、不同初相的简谐波叠加而成的复合波形。当信号通过线性时不变系统时，频域输入输出关系为：

  • 恒定群延迟消除相位色散：若相位呈线性关系，对频率求导得到的群延迟（Group Delay）为常数： τg(ω)=−dθ(ω)dω=τ\tau_g(\omega) = -\frac{d\theta(\omega)}{d\omega} = \tauτg​(ω)=−dωdθ(ω)​=τ 这意味着所有通过滤波器的频率分量在时间轴上经历相同的延迟步调，不会因为低频慢、高频快而发生频率相关的相对错位——即消除了相位色散（Phase Dispersion）。否则，一旦各谐波步调错乱，原本正常的生理波形就可能被扭曲出伪病理特征。
  • 线性相位不等于幅度恒定：由 Y(ejω)=A(ω)X(ejω)ej(−ωτ+θ0)Y(e^{j\omega}) = A(\omega) X(e^{j\omega}) e^{j(-\omega\tau + \theta_0)}Y(ejω)=A(ω)X(ejω)ej(−ωτ+θ0​) 可见，各频率分量的幅值仍然受到 A(ω)A(\omega)A(ω) 的加权调制。如果滤波器的截止频率设置不当，将目标信号自身包含的有效高频谐波一并衰减了，那么即便群延迟严格恒定，输出复合波形依然会发生幅度失真。

因此，严格的时域波形保真需要在信号有效频带内同时满足“幅度响应近似平坦”与“过原点的严格线性相位（θ0=0\theta_0 = 0θ0​=0）”。

FIR 的结构优势：系数中心对称即得广义线性相位

FIR 滤波器拥有一个清晰的代数性质：只要冲激响应序列 h[n]h[n]h[n] 满足中心偶对称或中心奇对称，系统就具有广义线性相位（Generalized Linear Phase）：

  • 取负号（-，奇对称，对应后文 Type III、Type IV）：带有固定相位偏置 θ0=±π2\theta_0 = \pm\frac{\pi}{2}θ0​=±2π​，常用于微分器与希尔伯特变换器。

五、 进阶演进：Parks-McClellan 等波纹逼近

窗函数法虽然物理图景直观、代码闭式简单，但从优化角度看，它的误差分布是被动由窗函数决定的：在靠近过渡带边缘处误差最大（往往成为卡住指标的短板），而到了高频远端衰减又远远超出实际指标需求，未能充分盘活有限抽头数所提供的自由度预算。

由此自然引出一个面向指标的最优化问题：给定目标频带集合 Ω\OmegaΩ（如通带 [0,ωp][0, \omega_p][0,ωp​] 与阻带 [ωs,π][\omega_s, \pi][ωs​,π]）、期望实幅度响应 D(ω)D(\omega)D(ω) 以及各频带的误差权重函数 W(ω)W(\omega)W(ω)，能否直接搜寻一组系数，使得加权最大绝对误差最小化？

3. 工程选型

  • 通带延伸至 Nyquist（ω=π\omega = \piω=π）的高通滤波：若要求通带不引入 ±90∘\pm 90^\circ±90∘ 希尔伯特相移（采用偶对称结构，如使用 scipy.signal.firwin()），抽头长度 LLL 应取奇数（阶数 NNN 为偶数），生成 Type I 结构；若应用场景本身需要或容许 90∘90^\circ90∘ 相移（如高频微分/正交变换），偶数抽头的 Type IV 结构在幅频上可以覆盖 ω=π\omega = \piω=π。
  • 标准带阻滤波（Bandstop）：由于带阻同时要求直流 ω=0\omega = 0ω=0 与最高频 ω=π\omega = \piω=π 均处于非零通带，对照结构表可知 Type II（死于 π\piπ）、Type III（死于 000 和 π\piπ）、Type IV（死于 000）全部受制于端点强制零点——在全部四种广义线性相位 FIR 结构中，标准带阻滤波器只能选用奇数抽头偶对称的 Type I 结构。

1. 基于 freqz 验算的闭环参数设计

实际业务给定指标后（例如：采样率 fs = 500 Hz，保留 0~50 Hz 心电有效成分，将 75 Hz 以上干扰衰减至少 50 dB），经验公式通常只适合估算抽头数初值，最终指标是否达标仍需通过频响验算确认。

工程上更稳妥的做法是：先按 3.3 / df 估算起点，再外包一层 freqz 验算循环每次加 2（保持奇数抽头 Type I），直到通带波纹和阻带衰减同时满足要求：

import numpy as np
import scipy.signal as signal

def design_lowpass_fir(
    fs: float,
    f_pass: float,
    f_stop: float,
    pb_ripple: float = 0.01,
    sb_atten_db: float = 50.0,
    method: str = "remez",
):
    delta_s = 10.0 ** (-sb_atten_db / 20.0)
    df = (f_stop - f_pass) / fs
    L = int(np.ceil(3.3 / df))
    if L % 2 == 0:
        L += 1
    if method == "remez":
        # Remez 通常能以更少的抽头数达标，从更小奇数起搜
        L = max(11, (L // 2) | 1)

    while L <= 1001:
        if method == "hamming":
            # 窗函数法把截止频率放在过渡带中点
            b = signal.firwin(L, (f_pass + f_stop) / 2.0, fs=fs, window="hamming")
        elif method == "remez":
            b = signal.remez(
                L,
                [0.0, f_pass, f_stop, fs / 2.0],
                [1.0, 0.0],
                weight=[1.0, pb_ripple / delta_s],
                fs=fs,
            )
        else:
            raise ValueError(f"Unsupported method: {method}")

        w, h = signal.freqz(b, worN=4096, fs=fs)
        pb_err = np.max(np.abs(np.abs(h[w <= f_pass]) - 1.0))
        sb_db = 20.0 * np.log10(np.max(np.abs(h[w >= f_stop])))
        if pb_err <= pb_ripple and sb_db <= -sb_atten_db:
            return b, pb_err, sb_db
        L += 2
    raise RuntimeError("在预设上限内未能收敛达标")

# 实测：fs=500Hz, 通带 0~50Hz (误差<=0.01), 阻带 >=75Hz (衰减>=50dB)
# hamming 输出: L=67 (66阶), 延迟 66.0ms, sb=-51.74 dB
# remez   输出: L=49 (48阶), 延迟 48.0ms, sb=-51.72 dB

在这组真实参数下，将 method 从 "hamming" 切换为 "remez"，抽头数从 67 降到 49，运行期乘加次数减少约 27%，群延迟也从 66 ms 缩短至 48 ms。

2. 流式落地与时间戳对齐：环形缓冲区实现 + 延迟补偿

一旦设计好静态系数数组 coeffs（在 C / Rust / Kotlin / Python 嵌入式或后端服务中可作为常量数组硬编码进内存），实时流式处理的核心就是一个零动态内存分配的环形缓冲区：

class StreamingFIR:
    """逐样本实时流式 FIR（实测与 scipy.signal.lfilter 输出差异在 1e-16 级）"""
    def __init__(self, coeffs: np.ndarray):
        self.h = np.asarray(coeffs, dtype=float)
        self.L = len(self.h)
        self.buf = np.zeros(self.L, dtype=float)
        self.idx = 0

    def step(self, x_new: float) -> float:
        self.buf[self.idx] = x_new
        acc = 0.0
        pos = self.idx
        for k in range(self.L):
            acc += self.h[k] * self.buf[pos]
            pos = (pos - 1) % self.L
        self.idx = (self.idx + 1) % self.L
        return acc

关于群延迟对齐，在线与离线场景的处理方式有所不同：

  • 实时在线流（比如蓝牙设备实时绘制心电曲线、多通道同步打标）：实时流无法读取未来样本，当前时刻输出的 y[n] 对应的是 (L - 1) / 2 个采样周期之前的信号状态。如果需要给特征峰（比如 R 波峰值）打精确时间戳，应当用当前采样时间减去 ((L - 1) / 2) / fs 秒。
  • 离线批处理 / 已落盘录像回放：如果整段数组 x 已经在内存中，既可以直接切片对齐 y_aligned = signal.lfilter(b, 1.0, x)[tau:]，也可以调用 scipy.signal.filtfilt(b, 1.0, x)（正向滤波后再反向滤波一遍，实现绝对零相移，代价是计算量翻倍且等效幅度响应变为原响应的平方）。

九、 结语

从时域滑窗点积到四类对称结构，FIR 滤波器的核心权衡体现在计算开销（抽头数 LLL）、系统延迟（群延迟 L−12\frac{L-1}{2}2L−1​）、过渡带陡度与阻带衰减深度四项指标的互相制约：窗函数法通过平滑窗包络换取旁瓣抑制，Parks-McClellan 算法则借助等波纹优化按指标重分配各频带的误差预算。

同时需要明确一点：FIR 并不意味着在所有指标上都优于 IIR。FIR 的优势在于容易构造严格线性相位且无极点稳定性隐患；但在不敏感于相位失真、同时又要求窄过渡带与极低算力/低延迟的嵌入式场景中，往往需要较长的抽头数组才能追平低阶 IIR 的幅频滚降能力。
