前言：计算开销与滤波器选型

在《痛苦系列 04》中，我们讨论了 FIR 滤波器的设计。为了追求严格的“线性相位”和保真波形，FIR 滤波器通常需要数十乃至上百阶的抽头系数，计算量相对较大。

但在资源受限的嵌入式系统或低功耗硬件中： 主频有限、存储空间紧缺，同时对处理延迟有严格要求。如果直接运行高阶 FIR 滤波器，可能会占用过多 CPU 周期。

这就引出了 无限冲激响应滤波器（IIR, Infinite Impulse Response）。它通过引入输出反馈与“极点（Poles）”，可以用较低的阶数实现陡峭的幅频响应。然而，极点的引入也带来了相位非线性，并在定点数计算环境下带来了潜在的稳定性问题。

  3. 第一性原理推导：基于梯形数值积分推导双线性变换（Bilinear Transform）。

  5. 定点量化效应：高阶直接型滤波器的数值不稳定性与二阶节（SOS）级联结构。

一、 结构特点：极点反馈带来的计算效率优势

FIR 滤波器是一个纯粹的前向卷积系统，输出只取决于输入序列的加权和。 而 IIR 滤波器的核心特征，是引入了输出反馈（Feedback）： y[n]=∑k=0Mbkx[n−k]−∑k=1Naky[n−k]y[n] = \sum_{k=0}^{M} b_k x[n-k] - \sum_{k=1}^{N} a_k y[n-k]y[n]=∑k=0M​bk​x[n−k]−∑k=1N​ak​y[n−k]

当前时刻的输出 y[n]y[n]y[n]，不仅取决于当前及过去的输入 x[n−k]x[n-k]x[n−k]，还取决于历史输出 y[n−k]y[n-k]y[n−k]。

对差分方程两边进行 Z 变换，得到系统传递函数： H(z)=Y(z)X(z)=∑k=0Mbkz−k1+∑k=1Nakz−kH(z) = \frac{Y(z)}{X(z)} = \frac{\sum_{k=0}^{M} b_k z^{-k}}{1 + \sum_{k=1}^{N} a_k z^{-k}}H(z)=X(z)Y(z)​=1+∑k=1N​ak​z−k∑k=0M​bk​z−k​

分母多项式 A(z)A(z)A(z) 的引入，使得系统在复平面上具有极点（Poles）。

在《痛苦系列 03》中我们讨论过，当极点位于单位圆内侧且靠近边界时，会在对应频率处产生明显的增益提升。利用这一特性，可以在较低阶数下构造出陡峭的过渡带。

仿真对比：IIR 与 FIR 达到相似幅频指标时的阶数差异 红线为 4 阶椭圆低通滤波器；橙线为达到接近过渡带与阻带抑制要求的 121 阶 FIR 滤波器。在幅频指标接近的前提下，IIR 滤波器的乘加运算量显著减少。

二、 继承历史：模拟时代的四大经典原型

既然 IIR 滤波器的极点拥有如此强大的性能，我们该如何计算这些极点和零点的坐标呢？

在数字信号处理发展初期，工程师们发现不需要从头重新发明一套极点配置理论——直接继承模拟电路时代在连续时间（SSS 平面）上已经推导成熟的模拟滤波器原型即可。

在连续时间 SSS 平面上，最著名的四大经典滤波器原型各具鲜明的工程权衡取舍：

实验对比：四大模拟滤波器原型在同为 4 阶下的频率响应 在同等阶数（N=4N=4N=4）与同等截止频率约束下：

  • 巴特沃斯（Butterworth）：通带内具备最大平坦度（Maximal Flatness），无任何波纹起伏，但滚降过渡带最平缓；
  • 切比雪夫 I 型（Chebyshev Type I）：通带内允许存在等幅波纹，换取了比巴特沃斯明显更陡峭的过渡带；
  • 切比雪夫 II 型（Chebyshev Type II）：通带内严格单调平坦，允许阻带内存在波纹；
  • 椭圆滤波器（Elliptic / Cauer）：通带和阻带内均允许存在等幅波纹，在相同阶数下换取了最为极致、近乎垂直的断崖式滚降。

在实际工程选型中，如果我们追求极致的算力节约和滚降陡峭度，椭圆滤波器往往是首选；如果系统对通带平坦度要求苛刻，巴特沃斯则是最稳健的选择。

三、 从数值积分推导双线性变换（Bilinear Transform）

现在，模拟滤波器的传递函数 Ha(s)H_a(s)Ha​(s) 已经由先辈们推导完备。但 Ha(s)H_a(s)Ha​(s) 处于连续的 SSS 平面上，模拟频率 Ω\OmegaΩ 是一条从 −∞-\infty−∞ 到 +∞+\infty+∞ 无限延伸的虚轴。 而数字计算机运行在离散的 ZZZ 平面上，数字频率 ω\omegaω 只是单位圆上从 −π-\pi−π 到 +π+\pi+π 的一段圆周。

四、 频率畸变与预畸变校正（Pre-warping）

双线性变换完成了 SSS 平面左半平面到 ZZZ 平面单位圆内部的单射映射。我们将连续频率 s=jΩs = j\Omegas=jΩ 和离散频率 z=ejωz = e^{j\omega}z=ejω 代入代换公式中：

为什么必须使用“频率预畸变（Pre-warping）”？

由于高频处存在严重的非线性正切压缩，如果你想设计一个数字截止频率为 ωc=100 Hz\omega_c = 100\text{ Hz}ωc​=100 Hz 的低通滤波器，若直接将 100 Hz100\text{ Hz}100 Hz 作为模拟原型参数，经过双线性变换压缩后，实际数字截止频率可能会发生严重偏移（比如偏到了 80 Hz80\text{ Hz}80 Hz）。

为了消除这种频率畸变，标准工程设计流程必须执行预畸变校正（Pre-warping）：

  1. 反向计算预畸变模拟频率： Ωc=2Ttan⁡(ωcT2)\Omega_c = \frac{2}{T} \tan\left(\frac{\omega_c T}{2}\right)Ωc​=T2​tan(2ωc​T​)
  2. 根据 Ωc\Omega_cΩc​ 设计模拟滤波器原型 Ha(s)H_a(s)Ha​(s)；
  3. 将双线性代换 s=2T1−z−11+z−1s = \frac{2}{T}\frac{1-z^{-1}}{1+z^{-1}}s=T2​1+z−11−z−1​ 代入 Ha(s)H_a(s)Ha​(s)，映射回数字系统 H(z)H(z)H(z)。经过正切压缩后，实际数字截止频率将被精确锚定在预设的 ωc\omega_cωc​ 处。

五、 致命混叠：为什么淘汰“脉冲响应不变法”？

在数字信号处理历史上，除了双线性变换，还存在另一种直观的转换方法——脉冲响应不变法（Impulse Invariance）。

它的设计初衷非常简单：让数字滤波器的单位冲激响应 h[n]h[n]h[n]，严格等于模拟滤波器冲激响应 ha(t)h_a(t)ha​(t) 的等间隔采样： h[n]=ha(nT)h[n] = h_a(nT)h[n]=ha​(nT)

初听起来，这种方法在时域上保留了完美的波形特性。但在频域上，它存在一个致命缺陷：采样必然带来频域混叠。

H(ejω)=1T∑k=−∞∞Ha(jω−2πkT)H(e^{j\omega}) = \frac{1}{T} \sum_{k=-\infty}^{\infty} H_a\left( j\frac{\omega - 2\pi k}{T} \right)H(ejω)=T1​∑k=−∞∞​Ha​(jTω−2πk​)

因为实际的模拟低通滤波器在高频区域只是渐近衰减，并不严格等于 0。当时域进行离散采样时，高于 Nyquist 频率的模拟高频能量会全部折叠回低频与中频带内。

对比验证：脉冲响应不变法的混叠上翘 vs 双线性变换 红线为脉冲响应不变法设计的频响：由于高频能量折叠混叠，在 Nyquist 频率 π\piπ 附近，阻带频响极其反常地“翘了起来”，无法有效抑制高频噪声；而蓝线为双线性变换法：通过非线性频率压缩，在 ω=π\omega = \piω=π 处增益被严格钉死在 0，彻底杜绝了混叠。这就是工程实践中几乎全部采用双线性变换的核心原因。

六、 定点量化问题与二阶节（SOS）的工程解法

讲到这里，IIR 滤波器在理论层面似乎已经完备。然而在嵌入式工程落地中，许多初学者在将 Python 仿真出的浮点系数移植到单片机后，经常会遭遇系统故障：滤波器运行一段时间后，输出数据突然发散，变成无效值或数值溢出（NaN / Inf）。

这背后的根本原因，就是定点运算字长效应（Fixed-point Quantization Effect）。

数学根源：高阶多项式根对系数摄动的超敏性

在 Python 中，运算使用的是 64 位双精度浮点数，截断误差极小；而在资源紧张的嵌入式 MCU 中，为了计算速度，通常使用 16 位定点数（Fixed-point）存储系数。

一个高阶 IIR 滤波器的分母多项式展开为： A(z)=1+a1z−1+a2z−2+⋯+aNz−N=∏i=1N(1−piz−1)A(z) = 1 + a_1 z^{-1} + a_2 z^{-2} + \dots + a_N z^{-N} = \prod_{i=1}^{N} (1 - p_i z^{-1})A(z)=1+a1​z−1+a2​z−2+⋯+aN​z−N=∏i=1N​(1−pi​z−1)

当滤波器阶数较高（如 N≥6N \ge 6N≥6）且过渡带很窄时，极点 pip_ipi​ 会密集分布在单位圆内侧的边缘（例如模长 r=0.98r = 0.98r=0.98）。 数学上著名的 Wilkinson 多项式效应 指出：高阶多项式的展开系数 aka_kak​ 对多项式的根（极点位置）具有极强的敏感度。系数末位哪怕发生微小的量化截断，也会导致计算出的极点位置发生剧烈偏移。

在 16 位定点量化下，原本位于圆内的极点极易被微小误差直接推到单位圆之外（∣p∣>1|p| > 1∣p∣>1）！极点一旦越过单位圆边界，系统冲激响应立刻转为指数发散，导致系统崩溃。

结构优化：二阶节级联（SOS, Second-Order Sections）

为了降低高阶系统对系数截断的敏感性，工程上通常避免直接实现高阶直接型结构（Direct Form），而是将其因式分解为多个独立的二阶滤波器串联，即 SOS（Second-Order Sections）结构。

H(z)=g⋅∏k=1Kb0k+b1kz−1+b2kz−21+a1kz−1+a2kz−2(K=⌈N/2⌉)H(z) = g \cdot \prod_{k=1}^{K} \frac{b_{0k} + b_{1k}z^{-1} + b_{2k}z^{-2}}{1 + a_{1k}z^{-1} + a_{2k}z^{-2}} \quad \left(K = \lceil N/2 \rceil\right)H(z)=g⋅∏k=1K​1+a1k​z−1+a2k​z−2b0k​+b1k​z−1+b2k​z−2​(K=⌈N/2⌉)

输入 x[n] ──► [ 二阶节 1 ] ──► [ 二阶节 2 ] ──► ... ──► [ 二阶节 K ] ──► 输出 y[n]

在 SOS 结构中，每一对共轭复极点仅由当前二阶节的两个分母系数 a1k,a2ka_{1k}, a_{2k}a1k​,a2k​ 决定。各节之间的极点完全解耦，切断了高阶系数误差的放大效应。

仿真对比：16位定点量化下 直接型 vs 二阶节（SOS）结构 设计一个 8 阶椭圆低通滤波器：

  • 灰色虚线：理想 64 位浮点精度下的频响；
  • 红线：将系数直接量化为 16 位定点数后，直接型（Direct Form）的频响发生严重畸变；
  • 蓝线：在完全相同的 16 位定点精度下，将其重构为 4 个二阶节串联（SOS）结构，系统频响与浮点参考曲线高度吻合。

作者按：在嵌入式音频与传感器信号处理中，直接型高阶 IIR 极易受到字长效应的影响。四阶以上的 IIR 滤波器，在实际工程实现中通常推荐采用 SOS 级联形式。

七、 结语与工程反思

对比 FIR 与 IIR，我们能清晰地看到两种截然不同的工程哲学：

  • FIR 滤波器：选择了一条稳健的道路。它放弃了反馈，用较大的计算阶数与时域延迟换取了绝对的线性相位与无条件稳定；
  • IIR 滤波器：选择了一条追求极致效率的道路。它引入极点反馈，用微小的阶数撬动陡峭的频率响应；但必须用双线性变换预校正其频率畸变，用 SOS 结构隔离其量化失稳风险。

在工程实践中，没有绝对优劣的算法，只有对约束条件的权衡与驾驭。
