前言

在《痛苦系列 01》与《02》中，我们讨论了连续信号的时域离散化，以及借助 DTFT 和 DFT 将时域波形转换到频域进行分析的方法。

在前面的讨论中，我们主要分析有限长序列，以及能够满足常规傅里叶变换收敛条件的序列。对于离散时间序列，绝对可和条件：

∑n=−∞∞∣x[n]∣<∞\sum_{n=-\infty}^{\infty} |x[n]| < \infty∑n=−∞∞​∣x[n]∣<∞

是保证 DTFT 绝对收敛且频谱连续的充分条件，但并非 DTFT 在所有数学意义下存在的必要条件（例如有限能量序列可以在均方意义下定义 DTFT，某些周期信号也可以借助 Dirac 冲激广义函数进行描述）。

本篇为了清晰地讨论级数收敛与系统稳定性，重点关注 Z 变换的绝对收敛域（ROC）。在离散系统分析中，信号或系统的冲激响应并不总是衰减的。例如一个包含正反馈的二阶系统，或者一个指数增长的序列：

x[n]=2nu[n](n=0,1,2,… )x[n] = 2^n u[n] \quad (n = 0, 1, 2, \dots)x[n]=2nu[n](n=0,1,2,…)

如果直接将其代入常规的 DTFT 级数：

X(ejω)=∑n=0∞2ne−jωn=∑n=0∞(2e−jω)nX(e^{j\omega}) = \sum_{n=0}^{\infty} 2^n e^{-j\omega n} = \sum_{n=0}^{\infty} \left(2 e^{-j\omega}\right)^nX(ejω)=∑n=0∞​2ne−jωn=∑n=0∞​(2e−jω)n

一、 从 DTFT 到 Z 变换：衰减因子与复变量 z

对于指数发散的序列 x[n]=2nu[n]x[n] = 2^n u[n]x[n]=2nu[n]，直接求和会导致发散。一个直接的数学处理思路是：人为给序列乘以一个指数衰减因子 r−nr^{-n}r−n（其中 r>0r > 0r>0），强行将其压制为收敛序列。

设原始序列每步放大 2 倍，我们选取 r=3r = 3r=3（即衰减项 3−n3^{-n}3−n），则加权后的序列变为：

x[n]⋅r−n=2n⋅3−n=(23)nx[n] \cdot r^{-n} = 2^n \cdot 3^{-n} = \left(\frac{2}{3}\right)^nx[n]⋅r−n=2n⋅3−n=(32​)n

由于公比模长小于 1，随着 nnn 的增大，加权后的序列迅速衰减趋向于 0。

三、 收敛域的几何形态与稳定性条件

收敛域在复平面上的几何形状并非随机产生，而是直接由等比级数公比模长小于 1 的条件决定：

  1. 因果序列（右边序列，n≥0n \ge 0n≥0）：

    • 展开项中含 z−nz^{-n}z−n，即 zzz 位于分母；
    • 公比形式为 q∝1zq \propto \frac{1}{z}q∝z1​；
    • 为使 ∣q∣<1|q| < 1∣q∣<1，要求分母模长足够大，即 ∣z∣>R|z| > R∣z∣>R；
    • 收敛域表现为某个圆盘向外的开阔区域。

  2. 反因果序列（左边序列，n<0n < 0n<0）：

    • 展开项中含 z∣n∣z^{|n|}z∣n∣，即 zzz 位于分子；
    • 公比形式为 q∝zq \propto zq∝z；
    • 为使 ∣q∣<1|q| < 1∣q∣<1，要求分子模长足够小，即 ∣z∣<R|z| < R∣z∣<R；
    • 收敛域表现为某个圆盘向内的区域。

  3. 双边序列：

    • 同时包含正负时间项，收敛域一般为内外极点之间的圆环区域 R1<∣z∣<R2R_1 < |z| < R_2R1​<∣z∣<R2​（边界可能根据信号具体情况退化）。

系统 BIBO 稳定的充要条件

线性时不变系统（LTI）满足 BIBO（有界输入有界输出）稳定的充要条件是：其冲激响应绝对可和：

∑n=−∞∞∣h[n]∣<∞\sum_{n=-\infty}^{\infty} |h[n]| < \infty∑n=−∞∞​∣h[n]∣<∞

由于在单位圆上（∣z∣=1|z| = 1∣z∣=1），有 ∣z−n∣=1|z^{-n}| = 1∣z−n∣=1，因此单位圆上的 Z 变换级数绝对收敛，当且仅当冲激响应绝对可和。

由此可得，LTI 系统满足 BIBO 稳定的充要条件是其系统函数的收敛域完整包含单位圆：

{z:∣z∣=1}⊆ROC{H(z)}\{z : |z| = 1\} \subseteq \text{ROC}\{H(z)\}{z:∣z∣=1}⊆ROC{H(z)}

对于因果有理系统，由于其收敛域是从最外侧极点向外延伸的开阔区域，这一条件又等价于：其全部未被消去的极点严格位于单位圆内部（∣pk∣<1|p_k| < 1∣pk​∣<1）。

四、 零极点与系统频率响应

将离散系统的传递函数写为零极点形式：

  • 分子为 0 的根 zkz_kzk​ 称为零点（Zeros）；
  • 分母为 0 的根 pkp_kpk​ 称为极点（Poles）。

1. 复平面上的曲面模型

为了直观理解零极点如何塑造系统的频响特性，我们可以将复平面上的模值 ∣H(z)∣|H(z)|∣H(z)∣ 视作一张受零极点约束的三维曲面：

  1. 极点：分母趋向于 0，使曲面向上隆起形成高耸的山峰。极点靠近单位圆时，会在对应频率处产生明显的谐振或通带放大；
  2. 零点：分子为 0，使曲面高度降为零。零点落在单位圆上时，会将对应频率的响应完全压低至零（陷波）；
  3. 频率响应（DTFT）：正是沿着单位圆周 ∣z∣=1|z| = 1∣z∣=1 截取的一圈曲面高度变化。

三维曲面：复平面零极点曲面与单位圆截面频响 图中山峰由极点顶起，青色粗线为沿单位圆截取的频率响应曲线。

六、 仿真设计：50Hz 陷波器与差分方程实现

在尚未系统展开 FIR 与 IIR 滤波理论之前，我们通过一个 50Hz 陷波器的极简设计，来演示前面讨论的零极点几何关系是如何直接转化为工程代码的。这不仅是一次“复平面图纸到硬件实现”的演练，更展示了 Z 变换如何回答“时域差分方程系数从何而来”的核心问题。

设计设定

假定系统采样率为 fs=1000 Hzf_s = 1000\text{ Hz}fs​=1000 Hz。我们希望滤除信号中存在的 50Hz 干扰，同时尽量保证其他频率信号的幅值不受影响。

1. 计算目标角频率

采样率 fs=1000 Hzf_s = 1000\text{ Hz}fs​=1000 Hz 对应角频率 2π2\pi2π。因此 50Hz 对应的数字角频率为：

2. 放置零点以形成陷波点

为了在 50Hz 处实现完全抑制，在单位圆对应的角度上配置一对共轭零点（模长为 1，角度为 ±0.1π\pm 0.1\pi±0.1π）：

3. 放置极点以收窄阻带

若只使用这一对零点，零点引起的衰减会波及较宽的邻近频带。

为了收窄陷波宽度，在完全相同的角度方向、略微靠内的位置（取半径 r=0.95r = 0.95r=0.95）放置一对共轭极点：

p1=0.95ej0.1π,p2=0.95e−j0.1πp_1 = 0.95 e^{j 0.1\pi}, \quad p_2 = 0.95 e^{-j 0.1\pi}p1​=0.95ej0.1π,p2​=0.95e−j0.1π

在偏离 50Hz 的频带上，极点与零点距离接近，幅值相互抵消，使得通带响应迅速恢复平坦。

4. 极点参数的工程取舍：频带宽度与时域代价

在这里，可能会产生一个实际追问：为什么极点半径选 r=0.95r = 0.95r=0.95？如果为了让陷波凹槽更窄、更陡峭，直接选 r=0.999r = 0.999r=0.999 是否更好？

在实际工程设计中，极点位置的选择是一个典型的综合权衡（Trade-off）：

  • 频域陡度 vs 时域瞬态振铃（Ringing）： 极点模长 rrr 越逼近 1，陷波凹槽确实越狭窄，对 50Hz 以外信号的误伤越小；但根据前文的模态分析，冲激响应衰减速度由 rnr^nrn 决定。若取 r=0.999r = 0.999r=0.999，系统冲激响应衰减极慢。一旦输入信号中混入脉冲或台阶阶跃扰动，时域会拖出长达数百甚至上千个采样点的高频振荡（振铃），系统需要很长时间才能恢复平稳；
  • 定点硬件截断与极点外漂（有限字长效应）： 在 PC 端的双精度浮点环境下，r=0.999r = 0.999r=0.999 是稳定的；但在许多基于 16 位定点 DSP 或低成本微控制器的嵌入式系统中，多项式系数必须定点截断。极点如果紧贴着单位圆、缺乏足够的安全裕量（Safety Margin），极微小的量化舍入误差就可能将极点踢出单位圆（∣p∣≥1|p| \ge 1∣p∣≥1），导致硬件系统一通电就自激震荡或输出顶死满轨。

工程中选择 r=0.95r = 0.95r=0.95，正是频域过渡带宽度、时域收敛速度与硬件数值安全三者权衡折中的结果。

七、 总结

Z 变换通过引入径向缩放因子，将原本局限于单位圆的傅里叶分析拓展到了整个复平面。

  • 收敛域（ROC） 是连接代数多项式与时域物理系统的桥梁，界定了系统的因果性与稳定性；
  • 极点 决定了系统的固有模态与稳定性边界，极点全部落在单位圆内是因果系统 BIBO 稳定的充要条件；
  • 零极点分布 直观反映了系统在各频段的响应特征，通过合理配置零极点的几何位置，可以直接推导出对应的时域差分方程。

Z 变换与傅里叶变换的工程分工

在实际工程中，很多初学者容易混淆 Z 变换与傅里叶变换的使用场景。其实二者有着清晰的分工：

  • 运行期（Runtime）看 FFT：FFT 吃进实时数据流、吐出离散频谱，直接用于波形监测、特征识别与频域滤波；
  • 设计期（Design Time）看 Z 变换：在工程代码跑起来的时候，硬件几乎不会去计算连续复变函数 X(z)X(z)X(z)。Z 变换的真正角色，是工程师在写代码之前，用来把频域滤波意图翻译成时域差分方程系数、并在部署前验算系统稳定边界与量化容错的“离线审查图纸”。
